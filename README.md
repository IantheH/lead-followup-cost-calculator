# Lead Follow-Up Cost Calculator

An interactive calculator that estimates what slow or missed lead follow-up could be costing your business.

- Enter leads per month, average sale value, close rate, and how fast new leads hear back
- See an estimate of the revenue left on the table each month and each year
- No email needed, and nothing is saved or sent. Everything runs in the browser
- A single file: open `index.html` to use it

The result is an estimate based on a simple planning assumption about how response speed affects closing. It is not a measurement of your business.
